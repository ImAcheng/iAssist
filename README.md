# iAssist
v1.0.0  
An Assistance Based LLM UI.

### Frameworks
.NET Core Windows Forms App + Antd UI

### Target LLM API
Ollama

### Build iAssist
1. Change the model name in source code to match your LLM.
2. Build it in Visual Studio

### Contribution
Language contributions are welcome.  
But you need to make sure your words are all correct.
